The free starter gives you the foundation: auth, one subscription plan, an admin panel, and the modules system this blog has been describing for months. It deliberately stops there. Pro is everything we kept building past that point, packaged as modules you install the same way.

## The gap between "it works" and "customers pay for it"

A working login form isn't an onboarding flow. A single Stripe price isn't team billing. Most of the work that makes a SaaS feel finished — the guided first five minutes, invites that actually land in someone's inbox, seats that update when a teammate leaves — is exactly the part that's easy to skip and expensive to build later. Pro is that part, already built.

## What ships in the module

Team invitations with owner, admin and member roles; seat-based Stripe billing that prorates when someone joins or leaves; a guided onboarding flow for a new workspace; transactional emails as React Email templates sent through Resend; account security with two-factor and session revocation; and an admin panel with real user management — roles, bans and logging in as a user.

## It's still modules, not a fork

Pro doesn't replace the free codebase — it adds to it. The same dev panel lists Pro modules alongside the free ones, and `pnpm modules:prune` works on them the same way: install what you're actually going to use, delete the rest.

## One payment, not another subscription

You're already paying for enough SaaS tools. Pro is a one-time payment for the private repository and lifetime updates, not a recurring line item.
