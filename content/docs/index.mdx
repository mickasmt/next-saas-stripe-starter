description: A modular foundation for your next SaaS.
---

This starter ships every module you usually need to launch a SaaS: authentication, billing, an admin panel, documentation, a blog and a changelog.

Each module can be switched off. A disabled module disappears from navigation, its routes return a 404 and its API endpoints are refused. Nothing is deleted, so you can switch it back on at any time.
